How to set up Supabase (free, one-time)
  1. Go to supabase.com → Start your project.
  2. Create a new project, then open SQL Editor and run the SQL below.
  3. Go to Project Settings → API. Copy the Project URL and anon key.
  4. Paste them below and click Connect.
create table if not exists church_data (
  key text primary key,
  value text not null,
  updated_at timestamptz default now()
);
alter table church_data enable row level security;
create policy "allow_all" on church_data for all using (true) with check (true);
alter publication supabase_realtime add table church_data;
Embed credentials in HTML Recommended

Paste into your HTML file (replace the empty quotes at the top of the script) so every device auto-connects.
