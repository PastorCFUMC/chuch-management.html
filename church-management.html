Cloud Sync Multi-Device

Connect to Supabase to access your data from any phone, tablet, or computer. Your data stays end-to-end encrypted — Supabase only stores the encrypted blob.

How to set up Supabase (one-time, free)
  1. Go to supabase.com → Start your project → sign in with GitHub.
  2. Click New project, choose your organization, name the project (e.g. "my-church"), set a database password, pick a region, click Create new project.
  3. Once the project is ready, click SQL Editor in the left sidebar. Paste the SQL below and click Run.
  4. Go to Project Settings → API. Copy the Project URL and the anon / public key.
  5. Paste them into the fields below and click Connect.
SQL to run in Supabase → SQL Editor:
create table if not exists church_data (
  key text primary key,
  value text not null,
  updated_at timestamptz default now()
);
alter table church_data enable row level security;
create policy "allow_all" on church_data
  for all using (true) with check (true);
alter publication supabase_realtime add table church_data;
